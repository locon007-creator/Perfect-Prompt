# Perfect Prompt

Personal prompt-generation engine based on the open-source Prompt Master project by Nidhin Joseph Nelson.

This repository now contains an independent copy of the Prompt Master prompt-engineering foundation so it can be customized into Perfect Prompt without depending on the upstream repository at runtime.

## Foundation

- `SKILL.md` — core prompt-engineering engine and routing logic
- `references/templates.md` — prompt architecture/template library
- `references/patterns.md` — prompt failure-pattern diagnostics
- `LICENSE` — original MIT license and copyright notice

## Upstream

Original project: `nidhinjs/prompt-master`

Perfect Prompt will diverge from the upstream project as it is customized for personal prompt-generation workflows.
